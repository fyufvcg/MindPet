# Agent 执行路径自查（2026-10-16）

本轮检查普通问答、联网查询、本地文件、同步/异步终端、SSH、Office、Skill/MCP、取消与恢复路径。检查基于代码、真实 Spring AI 工具循环配合脚本模型、本机 HTTP MCP，以及 Desktop executor 的隔离传输测试；未进行真实模型、真实远程服务器或桌面操作验收。

| 路径 | 处理结果 |
| --- | --- |
| 普通知识问答 | 模型可以直接回答，不强制规划、发现工具或搜索；有回归验证不会执行搜索。 |
| 联网查询 | 普通查询使用 web_search，摘要足够就回答。移除 browser_search 对所有搜索任务的强制要求，真实浏览器用于可见浏览器任务。 |
| 多来源引用 | 来源 ID 从 URL 摘要生成稳定数字编号，搜索和抓取同一 URL 使用同一编号；不同来源不再全部复用 S1。沿用前端数字引用格式。 |
| 文件阅读 | 所有文本默认最多 300 行、12000 字符，支持 offset/length 读取超长单行；不再把不存在的 foo.md 静默替换为 foo_已更新.md。 |
| 路径解析 | 已存在文件也验证 realpath 的授权范围，防止通过目录联接或符号链接读到范围外文件。 |
| 本地内容搜索 | rg 退出 1 表示无匹配；取消、超时、进程启动失败、输出缓冲溢出和其他错误保留为失败。 |
| 同步终端 | 保留 stdout/stderr/exitCode，非零退出不再标记成功。无匹配等命令语义可根据退出码和内容解释。 |
| 异步终端 | 启动成功只代表已启动；轮询包含运行状态、退出码和错误，非零退出与会话丢失标记失败。 |
| SSH | 同步执行支持取消和超时，保留退出码；关闭通道后不承诺远程进程或副作用已回滚。后台会话记录退出码和错误。 |
| Office | 按格式加载说明，修改已有文件前 inspect，完成后 validate；即使调用执行完成，只要 validation.valid=false，工具结果也标记失败。 |
| Skill/MCP | Skill 正文按需加载，Desktop 基础工具常驻，外部 MCP 限于本次选择范围。更新旧测试中的来源标记和外部服务发现样例以匹配当前架构。 |
| 长任务 | 回归覆盖多轮、预算、取消、恢复、工具调用/结果配对、截图进入下一轮但不持久化图片、完整输出归档及分页、blocked 状态。 |

## 验证入口

- `MindPet`：`npm run test:agent-workflows`。18 个隔离测试执行真实 executor 代码，传输及终端进程使用桩，临时文件夹自动清理。
- `MindPet-java`：`mvn "-Dtest=AgentTaskServiceTest,AgentMcpBridgeTest" test`。29 个测试使用临时 SQLite、脚本模型和本机 HTTP MCP。全量后端回归 143 项通过。
- `MindPet`：`npm run build`，检查类型并生成 Electron 主进程、preload 和 renderer。

自动测试不能替代真实模型选择工具、复杂 Office 排版、第三方网站响应和实际 SSH 服务的验收。旧文字压缩阈值已由 [独立上下文预算](context-management.md) 替代；本地 tokenizer 和图片预留仍属于估算。


## MCP 与抓取超时修复

用户配置的外部 MCP 不按旧内置领域工具黑名单过滤，仍只对用户通过 `/` 选择的任务开放。前端并发握手合并，同配置失败后后台冷却 60 秒；初始化缺失目录子集不会关闭其他已连接服务。自动协议协商遇到 401/403 不再继续尝试 SSE。403 表示服务端拒绝，具体地址、Token 或账号限制需要服务端信息确认。

隐藏浏览器抓取改为 DOM 就绪、页面加载完成和有界轮询触发正文提取，不再只等待全部资源加载完成；仍保留总超时、取消和窗口清理。历史故障日志未包含目标 URL，不能仅凭恰好 30 秒判定具体站点的网络原因。

## 自动上下文改造

固定 N 轮、64000 字符阈值、最近两组工具响应/图片及前端估算阻断发送的策略已替换。原有测试入口保留；已执行全量后端测试、工具隔离测试及完整前端构建，结果见 [验证记录](agent-validation.md)。记忆算法不改动，原有归档摘要的批次参数独立命名。详见 [会话上下文管理](context-management.md)。


## 共享运行边界

- 模型与工具循环由 Spring AI 负责；外部 MCP 协议统一由 Electron 官方 SDK 处理，Java 通过本机鉴权桥接调用。
- 定时任务的配置、事务领取与执行适配拆成 Store、Scheduler、Runner；聊天工具和设置页复用同一 API，渲染窗口只观察状态。
- 任务恢复使用当前补充要求和当前 MCP 范围；结果未知的动作必须先检查，不因超时自动重试。
- 审批串行展示，取消或超时关闭对应提示；统计写入共用一个入口，避免聊天和计划互相覆盖。
- 已完成执行记录默认 90 天清理，可恢复任务、会话历史与长期记忆不受此策略影响。

仍有既有大文件职责、历史按需分页、多窗口统计事务及真实服务验收的改进空间；详见 [验证记录](agent-validation.md)。
