## 本轮全量回归发现并修复的问题

早期全量测试发现持久化脱敏失败：SQL 语法被当作正文处理，重复处理改写脱敏占位符。现已限制为 SQL 字面量数据处理，并让占位符保持幂等；测试另外补上生产数据库迁移和资源关闭，修复过期测试夹具遗漏的 `source_turn_hash` 列及 Windows 文件占用问题。最新全量结果已通过。

以上改动属于凭据脱敏与存储边界修复。长期记忆提取、检索、遗忘、Curator 与知识图谱算法未改动。
