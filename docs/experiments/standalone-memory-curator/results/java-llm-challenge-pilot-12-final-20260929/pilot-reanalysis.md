# 真实 LLM 试跑结果（12 条时间线）

## 结果性质

这是锁定测试集语言挑战子集的探索性试跑，覆盖 12 种场景各 1 条时间线，共 480 个用户回合、120 个检索问题和 120 个成对问答问题。模型为 `deepseek-flash`，温度 0；检索使用本地 `bge-m3` embedding。所有抽取、馆长和问答阶段均有真实 LLM 调用，没有使用 fixture 结果。

这不是正式锁定测试结论：本次试跑时 G1、G2 使用同一隔离 SQLite 文件下不同 user namespace；之后 runner 已改为双数据库。完整 60 条挑战集随后因模型服务返回 `HTTP 402 Insufficient Balance` 在基线构建阶段中止。

## 配对结果

| Recall@512 estimated tokens | 88.89% | 88.89% | 0.00 个百分点；95% CI [0.00, 0.00] |
| 自动问答正确率 | 78.33%（94/120） | 77.50%（93/120） | −0.83 个百分点；按用户 bootstrap 95% CI [−5.00, 3.33] |

问答由冻结的字符串、状态、禁止答案和拒答规则自动评分，没有人工盲审，也没有让模型给自己的回答打分。

## 馆长整理质量

按生产 `memory_fact` 字段重新计算，并显式归一化 `observed/confirmed` 与历史居住地谓词别名；日期状态和确定日期仍要求严格匹配：

- Micro：Precision 61.33%（46 TP、29 FP）、Recall 47.42%（46 TP、51 FN）、F1 53.49%。
- 按时间线宏平均：Precision 35.77%、Recall 47.92%、F1 40.92%；Macro F1 的按用户 bootstrap 95% CI 为 [21.23%, 60.89%]。
- 当前画像槽位：Precision 100%、Recall 52.17%（24/46）；12 条中只有 3 条时间线的预期画像槽位全部正确。
- 12 条中有 5 条时间线未完成馆长整理，生产校验拒绝主要涉及 polarity/uncertainty；其中一条还出现 confidence policy 拒绝。
- 已保存事实来源回合与原文证据均为 75/75。1 条合成敏感信息样本被完全拦截。显式日期和模糊时间处理分别为 0/1、0/1。

## 资源与延迟

- G1 检索语料：1,128 个 unit，估算 21,395 tokens。
- G2 检索语料：1,282 个 unit，估算 26,594 tokens，比 G1 增加 24.30%。因此事实投影本身的压缩估计不能代表完整系统压缩。
- 共记录 762 次模型调用、901,478 个 provider-reported tokens：G1 抽取 480 次 / 486,657 tokens；馆长 42 次 / 327,013 tokens；问答 240 次 / 87,808 tokens。
- 调用延迟 p95：G1 抽取 5.45 s，馆长 50.94 s，问答 1.47 s。

## 判读与文件说明

这组小样本没有证明馆长带来稳定增量：Recall@5 差距很小且区间下界为 0，固定 512-token 召回没有提升，问答点估计略低，实际 G2 检索语料更大；同时，事实召回和时间处理未达方案门槛。它适合作为脚本与模型链路的预试结果，不应用来声称馆长已通过正式评测。

`pilot-reanalysis.json` 保存从原始 retrieval、QA、memory-unit 和 SQLite 数据重新计算的结果；`reanalyze_pilot_metrics.py` 可重复该重算。原 `metrics.json` 受 G1/G2 大小写聚合错误及字段别名不一致影响，不应引用。完整 60 条中止运行的目录也有 `RUN-INCOMPLETE.md` 标记，明确没有形成完整指标。
