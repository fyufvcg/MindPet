# 星图展示约定

此说明描述星图前端效果和手动编辑入口，复用 MindPet 的主题变量，不替换全局设计系统。

- 画布：浅色使用冷灰蓝底，深色沿用深蓝主题。蓝紫色空间层次、非重复的稀疏星尘、少量星芒和弱等密度弧线仅提供空间感。背景为示意装饰，与真实记忆数量、关系、距离和统计无关，不遮挡文字。
- 节点：中心用户为五角星，其余节点为四角星光，沿用低饱和类型色和柔和光晕。核心节点可缓慢呼吸；节点本身不持续移动。悬停和选中显示细环，突出已有关联。节点名称不随记忆保留度消失。
- 聚类：以事实连接计算静态星群布局；虚线语义层的显示开关不重新排列节点。星群底色没有数据含义，不代表新关系。
- 关系：事实为蓝色实线、带方向箭头，聚焦时显示谓词；语义相似为紫色虚线、无箭头，相似程度在检视器显示。类型色和线型共同表达含义。
- 淡化：前端以接口已有的重要度、实体类型、最后提及时间估算图谱保留度。光点、光晕与连线逐渐减弱，详情明确写作“展示保留度”。这不是后端状态更新，也不恢复后端已过滤的记录。
- 阅读：总览适当补偿名称缩放，极远视图只显示核心或聚焦名称。点击实体后聚焦其关联；窄屏检视器放在底部，选中实体上移，避免被遮挡。
- 动效：仅呼吸、虚线聚焦流动与短反馈过渡；减少动态效果偏好下，CSS 动画与镜头过渡停止。
- 编辑：工具栏新增实体和连线入口。点击起点、终点后在侧栏确认方向、关系类型和重要度，也可拖动连接点；选择起点不会触发镜头放大。节点检视器支持修改名称、类型、说明、重要度；事实关系可点击线条或列表编辑、删除。语义关系继续由系统计算。
- 写入：新增独立 `KnowledgeGraphEditingService` 和 API，操作现有图谱表，不改自动提取、检索及遗忘规则，不增加 schema。保存记录为 `manual:knowledge-graph` 来源；关系断言改变时用新的手动来源替换不再匹配的旧来源。仅改重要度时保留旧证据。所有写入为事务，校验用户归属、重复、类型、非自身连线。更新文字后重新嵌入，提供方不可用时清空旧向量并保存文字。
- 边界：手动事实按已有检索和遗忘规则工作，不自动永久保留；未来对话提取仍遵循原合并规则。名称为 User 的中心实体保留其识别名和人物类型，其说明及重要度可编辑。嵌入沿用用户现有配置，可能使用云端提供方。

机械检查中的图例三角箭头“粗左边框”和图谱画布星点“平铺背景”为语义图例和真实画布用途，不作为普通卡片样式推广。类型色为现有色系的低饱和调整，不更改全局主色。
