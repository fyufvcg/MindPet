# 记忆画廊改版方案

## 1. 目标

本次改版包含“回忆星河”和“MindPet 记得”两个区域。

- “回忆星河”从中心卡片轮播改为漂浮在星空中的 3D 记忆长廊。用户通过鼠标滚轮沿纵深方向前进或后退，照片分布在路线左右两侧并朝向用户。
- “MindPet 记得”从展示对用户的客观归纳，改为展示 MindPet 因某段原文产生的第一人称想法。原始内容保留为依据，但不再作为卡片主题。
- 保留现有的照片分享、删除、刷新、记忆更正和原文查看能力。

## 2. 当前实现的问题

### 2.1 回忆星河

当前页面已经使用透视、Z 轴和旋转制造 3D 效果，但交互本质仍是中心卡片轮播：

- 当前记忆位于画面中央，其余卡片分布在左右远处。
- 滚轮每次只切换一个索引，并有 360 毫秒锁定。
- 鼠标横向拖拽也会切换卡片，页面使用 `grab` 和 `grabbing` 光标。
- 卡片和详情同时争夺视觉焦点，没有形成沿一条路线前进的空间关系。

### 2.2 MindPet 记得

当前卡片的主题和正文主要来自用户画像、用户洞察和长期记忆中的 `understanding`。它们描述“MindPet 知道了什么”，但还不是 MindPet 面向用户表达的想法。

当前接口已经能够提供准确匹配的用户原话、MindPet 当时的回复、照片和来源信息，这些内容可以继续作为“查看原文”的依据。

## 3. 回忆星河方案

### 3.1 空间结构

场景不绘制实体墙壁、地板或天花板，只用照片、星点、薄雾和微弱的纵深光带暗示一条漂浮在星空中的路线。

- 用户视角位于路线中央，朝时间深处观看。
- 照片沿路线左右交替排列，并在纵深方向保持固定的基础间距。
- 左侧照片向路线中央旋转，右侧照片反向旋转，保证照片正面始终偏向用户视角。
- 相邻照片在高度和横向距离上允许小幅变化，避免形成完全对称的展板阵列。
- 最新记忆位于入口附近，向前移动进入更早的记忆；反向滚动回到较新的记忆。
- 近处照片清晰、尺寸较大，远处照片缩小并降低对比度。不要使用明显模糊覆盖正文，以免造成眩晕和阅读困难。

### 3.2 卡片内容

长廊中的每张卡片只常驻显示：

- 照片；
- 日期；
- 简短标题。

标题最多两行，超出时截断。卡片不常驻展示故事、心情和 MindPet 的长回复，避免纵深场景变成文字墙。

点击照片后，在当前场景上方打开聚焦详情层，展示完整照片、故事、心情、时间以及“MindPet 当时对你说”的内容。关闭详情后返回原来的长廊位置。

### 3.3 滚轮移动

- 鼠标指针位于回忆星河场景内时，纵向滚轮控制前进和后退。
- 滚轮输入连续改变相机在 Z 轴上的位置，不再采用一次滚动切换一张卡片的离散逻辑。
- 停止滚动约 150 毫秒后，场景轻微吸附到最近的记忆位置，使照片和标题停在可阅读范围内。
- 触控板的小幅连续输入需要保持顺滑，普通鼠标滚轮的大步输入需要限制最大速度，避免一次跨过过多照片。
- 到达最早或最新记忆时给出轻微的阻尼反馈，不循环跳转到另一端。
- 移除横向抓取和拖拽切换，包括相关 Pointer Capture、拖拽偏移和 `grab/grabbing` 光标。
- 保留键盘方向键作为替代操作：上/左返回较新记忆，下/右进入更早记忆。

### 3.4 场景光标

进入回忆星河的可移动区域后，光标自动替换为与星空穿行相符的轻量导航光标。建议使用带小星点的前进指针，并提供系统光标回退。

- 普通场景：导航光标；
- 照片和按钮：标准可点击指针；
- 详情文字：标准文本或默认光标；
- “MindPet 记得”页面：恢复普通系统光标。

光标只改变指针图形，不添加跟随鼠标的大面积光效。

### 3.5 辅助导航

保留底部时间轴，但改为显示当前时间位置和可点击的记忆节点。时间轴点击后，相机平滑移动到目标记忆。顶部左右切换按钮可以保留，作为精确移动到相邻记忆的辅助入口。

## 4. MindPet 记得方案

### 4.1 内容层级

每条内容由三层组成：

1. 主题：这段原文让 MindPet 产生的核心想法，不是对原文的摘要。
2. MindPet 的话：使用第一人称“我”和第二人称“你”，直接对用户表达感受、理解或以后想如何陪伴用户。
3. 原文依据：用户当时说的话、MindPet 当时的回复、相关照片和来源时间，默认折叠，通过“查看原文”展开。

示例：

- 原文事实：用户说最近工作压力很大，但不希望被反复追问。
- 主题：给你一点不被打扰的陪伴
- MindPet 的话：我记得你累的时候不一定想立刻解释发生了什么。以后我会先陪你缓一缓，把询问放轻一些，等你愿意说时再认真听。

### 4.2 生成要求

生成内容必须遵守以下规则：

- 只依据已有原文和已确认记忆，不补充没有证据的事件、动机或心理诊断。
- 主题简短，建议不超过 18 个汉字。
- 正文使用 MindPet 第一人称，建议 60 至 160 个汉字。
- 表达重点是“这让我想到什么”和“以后我想怎样理解或陪伴你”，避免把用户画像换一种说法复述。
- 原文存在不确定性时，正文也要保留不确定语气。
- 不生成夸张承诺，不把一次性情绪描述为永久性人格。

### 4.3 保存到 llm_growth

第一人称想法生成后保存到 `llm_growth`，页面读取已保存结果，不在每次打开页面时重新生成。

建议使用以下数据约定：

| 字段 | 用途 |
| --- | --- |
| `category` | 固定为 `memory_reflection`，与现有 personality、preference、knowledge、style 成长记录区分 |
| `insight` | MindPet 第一人称正文，同时参与现有向量检索 |
| `context` | 生成时使用的原文背景，继续支持现有成长记忆语义 |
| `title` | 新增字段，保存展示主题 |
| `source_type` | 新增字段，记录来源类型，例如 profile、insight、memory 或 gallery |
| `source_id` | 新增字段，记录来源记录 ID |
| `created_at` | 首次生成时间 |
| `updated_at` | 新增字段，重新生成或来源修正后的更新时间 |

为 `(user_id, category, source_type, source_id)` 建立唯一约束，保证同一份原始记忆只对应一条展示想法。原文仍保存在原有对话、画像、洞察或照片记录中，不在 `llm_growth` 重复复制完整原文。

现有 `saveLlmGrowth` 的分类校验需要允许 `memory_reflection`。这类记录仍属于 MindPet 的成长内容，可以进入现有 LLM Growth 检索，使后续聊天自然体现这些理解。

### 4.4 生成时机

- 新记忆：记忆馆长确认用户画像、洞察或长期记忆后，异步生成对应想法并保存。
- 既有记忆：提供一次批量补全流程，只为缺少 `memory_reflection` 的来源生成内容。
- 页面接口只读取已经保存的想法。若后台仍在补全，页面显示“MindPet 正在整理这段想法”，不在 GET 请求中同步等待模型生成。
- 用户更正原始理解后，将对应想法标记为待更新，重新生成并更新原记录，不追加重复项。

### 4.5 展示方式

“MindPet 记得”继续使用纵向时间流，但卡片摘要改为：主题、第一人称正文摘录、来源日期。展开后先显示完整的 MindPet 想法，再提供“查看原文”。

“查看原文”区域按来源情况展示：

- 有准确对话证据：展示用户原话和 MindPet 当时的回复。
- 有关联照片：展示照片入口，可返回回忆星河对应位置。
- 只有馆长上下文但没有准确原话：明确标注“没有找到可核对的原始对话”，不能把馆长生成的上下文伪装成用户原话。

“这条理解需要更正”继续保留，更正对象应同时包含原始理解和由它生成的 MindPet 想法。

## 5. 状态和边界

### 5.1 数据数量

- 0 条：沿用空状态，引导用户分享第一段回忆。
- 1 至 8 条：扩大纵深间距，避免场景显得拥挤或像轮播。
- 9 至 60 条：正常长廊密度。
- 60 条以上：只渲染相机附近的照片节点，远处保留轻量占位，避免大量图片和 3D 图层影响性能。

### 5.2 图片异常

图片加载失败时显示统一的记忆占位图，同时保留日期和标题。不同宽高比的照片使用裁切预览，详情层展示完整比例。

### 5.3 动效和可访问性

- 系统开启“减少动态效果”时，禁用星空漂移和浮动呼吸，只保留短距离、低速度的纵深切换。
- 焦点样式、键盘导航和按钮语义继续保留。
- 光标替换不能成为唯一的可操作提示。

### 5.4 本次不做

- 不绘制真实的长廊建筑、墙壁或地板。
- 不加入第一人称自由飞行、方向键转向或鼠标视角旋转。
- 不允许用户在长廊中横向拖拽切换照片。
- 不在每次进入页面时重新生成 MindPet 想法。
- 不改变照片原图本地保存的现有规则。

## 6. 实施拆分

1. 数据层：扩展 `llm_growth` 的展示主题和来源关联字段，补充唯一约束和已有数据库迁移。
2. 生成层：增加第一人称想法生成规则、新记忆异步写入、旧记忆批量补全和更正后的更新逻辑。
3. 接口层：让记忆画像接口返回已保存想法、主题、来源和原文可用状态。
4. 回忆星河：重建双侧纵深布局、连续滚轮相机、吸附算法、节点虚拟化和场景光标，删除拖拽逻辑。
5. MindPet 记得：调整卡片信息层级和原文展开区，保留更正与照片跳转。
6. 验收：覆盖普通鼠标、触控板、键盘、明暗主题、减少动态效果、图片失败和大量照片场景。

## 7. 验收标准

- 用户不需要拖拽，仅通过滚轮即可明确感受到沿星空路线前进和后退。
- 任意可见照片都位于路线左侧或右侧，并朝向用户视角。
- 长廊卡片只显示照片、日期和简短标题。
- 停止滚动后，最近的照片位置稳定，文字可以阅读，不发生持续漂移。
- 离开回忆星河后，光标恢复为系统默认样式。
- “MindPet 记得”的卡片主题是由原文引发的想法，正文是 MindPet 对用户说的第一人称内容。
- 同一条来源记忆不会重复生成多条想法，重新打开页面时内容保持一致。
- 用户可以查看准确原文；没有准确原文时，界面明确说明，不展示伪造引用。
- 新想法实际写入 `llm_growth`，并能进入现有成长记忆检索。
